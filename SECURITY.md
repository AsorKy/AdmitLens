# Security Policy

## Scope

This is an educational repository. It uses synthetic data only and never
contains real protected health information (PHI). Anything that looks like real
patient data or a real credential in this repository is a bug and should be
reported.

## How to report a vulnerability

Use GitHub private vulnerability reporting: open the **Security** tab of this
repository and choose **Report a vulnerability**.

Please do not open public issues, pull requests or discussions for security
problems.

## What not to include in a report

- Real credentials, tokens, keys or connection strings.
- Real patient data or any other personal data.

Describe the problem and how to reproduce it using placeholders instead.

## Response expectations

This is a best-effort, educational project maintained by one person. There is
no guaranteed response time, but reports are read and handled as time allows.

## Repository protections

Secret scanning and push protection are enabled on this repository.
